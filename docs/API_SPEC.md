# ThinkStack API Specification

> Status: **draft** — endpoint surface and JSON shapes will be finalized with the Phase 1 controllers.
> Finalized here, then mirrored into `docs/api/openapi.yaml` (generated by springdoc and committed).

- Base URL: `http://localhost:8080` (prod path: `/api/v1`)
- Content type: `application/json`
- Auth: `Authorization: Bearer <JWT>` for protected endpoints
- Envelope: every JSON body is wrapped: `{ "success": bool, "message": string, "data": object, "timestamp": EpochMillis }`

## Health
| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| GET | `/api/v1/health` | none | Liveness + API version. `200` when up. |

## Planned surfaces (skeleton)
| Area | Base path | Notes |
| --- | --- | --- |
| Auth | `/api/v1/auth` | register, login, me |
| Categories | `/api/v1/categories` | list w/ spec defs, by slug |
| Products | `/api/v1/products` | list, get, by category |
| Specifications | `/api/v1/products/{id}/specifications` | values w/ explanations |
| Prices | `/api/v1/products/{id}/prices` | by seller, current + history |
| Reviews | `/api/v1/products/{id}/reviews` | CRUD |
| Wizard | `/api/v1/wizards` | list, get w/ questions |
| Decisions | `/api/v1/decisions/{sessionId}` | sessions, answers, alternatives |
| Recommendations | `/api/v1/decisions/{sessionId}/recommendations` | ranked + why |
| User | `/api/v1/users/me` | profile, preferences, DNA, journal, bookmarks, notifications |

## Errors
Standard HTTP codes; body uses the envelope with `success:false`, `message` = human-readable error, and `data` = machine error details. Exceptions are mapped in `com.thinkstack.exceptions.GlobalExceptionHandler`.
